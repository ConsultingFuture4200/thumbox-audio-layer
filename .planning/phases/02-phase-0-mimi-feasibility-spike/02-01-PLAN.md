From transformers (target API):
```python
from transformers import MimiModel, AutoFeatureExtractor

# Load with pinned revision (set in configs/models.lock.yaml)
model = MimiModel.from_pretrained("kyutai/mimi", revision="<SHA>")
feature_extractor = AutoFeatureExtractor.from_pretrained("kyutai/mimi", revision="<SHA>")

# Encode 16 kHz mono PCM → discrete audio tokens
inputs = feature_extractor(raw_audio=wav_array, sampling_rate=24000, return_tensors="pt")
encoder_outputs = model.encode(inputs["input_values"])  # returns audio_codes shape: [B, n_q, T]

# Decode tokens → reconstructed waveform
audio_values = model.decode(encoder_outputs.audio_codes)[0]  # shape: [B, 1, T_samples]
```

Mimi outputs at 12.5 Hz with n_q=8 codebooks of size 2048 (FR-AL-8 reference target).
Sample rate is 24 kHz, not 16 kHz — the spike must resample on input/output if test corpus is 16 kHz.
