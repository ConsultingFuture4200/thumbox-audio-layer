**Step 1 — Write `spike/probes/llm_on_tokens_probe.md`** (~40–60 lines):

Required sections (concrete content; no placeholders):

1. **Question framing** — restate SM-AL-2 verbatim. Define "coherent behavior" operationally for this experiment. Suggested operational definition (pin in writing): the LLM emits at least one well-formed English sentence (parsed as such by simple sentence-tokenization) where the sentence's content is recognizably *related to the input utterance's topic or intent*, even if not a transcription. This is intentionally weaker than "transcription accuracy" and weaker than "intent-classification accuracy" — PRD §10.1 stretch language is "any coherent behavior conditioned on audio tokens".

2. **Rubric — per-utterance classification** — exactly four buckets:
   - **`coherent`**: output is well-formed English AND topically related to input.
   - **`partially-coherent`**: output is well-formed English but topically unrelated (LLM is "thinking" but not conditioned on the input).
   - **`nonsense`**: output is not well-formed English (token salad, repetition, blank) — LLM is not "thinking".
   - **`error`**: forward pass crashed or shape mismatch — implementation issue, not a model behavior result.

3. **Aggregate verdict rule** — bind the SM-AL-2 binary outcome to bucket counts BEFORE running:
   - **PASS**: ≥ 4 of 20 utterances bucket as `coherent` (i.e., ≥ 20% coherent rate). Below this is statistical noise.
   - **MARGINAL**: 1–3 utterances bucket as `coherent`. Plan 05 must escalate; not a clean pass.
   - **FAIL**: 0 utterances bucket as `coherent`. SM-AL-2 fails; PRD §6.2 kill criterion triggered.
   - **INVALID**: ≥ 5 of 20 are `error`. The experiment didn't run cleanly; result is uninterpretable.

4. **Adapter caveat** — explicit acknowledgment that the adapter in this stretch is randomly-initialized, not trained. A null result here does NOT mean "audio tokens cannot work for an LLM" — it means "audio tokens cannot work for an LLM with an *untrained* adapter in two weeks." PRD §6.2 language is "within the 2-week timebox," which is the timebox for the stretch attempt, not for the entire codec-as-LLM-input research direction. This nuance MUST appear in the Plan 05 evaluation doc.

5. **Methodology** — the test set composition (Step 2 below); the model (Qwen2.5-0.5B); the runtime (`models.lock.yaml`); the seed; the max_new_tokens; the prompt template (e.g., LLM input is `inputs_embeds=adapter(mimi_encode(audio))` followed by a fixed text prefix like `"User said:"` decoded back through Qwen's input embeddings — document the exact wiring).

6. **Operator workflow** — for each of 20 utterances, the operator reads the LLM output, classifies into one of 4 buckets, optionally writes a one-sentence note. This is what makes the eval "manual" per PRD §6.1. Plan budget: ~15 minutes operator time.

**Step 3 — Implement `spike/src/spike/adapter.py`** (~50–80 lines):

```python
import torch
import torch.nn as nn

class MimiToQwenAdapter(nn.Module):
    """Untrained projection from Mimi audio codes to Qwen input embedding space.

    Architecture:
      - Per-codebook nn.Embedding(vocab_size, hidden_dim).
      - Sum across n_q codebooks (RVQ-style additive composition).
      - Output shape: [B, T_frames, hidden_dim].

    NOTE: This is intentionally NOT trained for the Phase 0 stretch. PRD §10.1
    stretch is whether the LLM produces *any* coherent behavior with this minimal
    setup; a null result does NOT condemn the codec-as-LLM-input direction — see
    spike/probes/llm_on_tokens_probe.md adapter caveat.
    """
    def __init__(self, n_q: int, vocab_size: int, hidden_dim: int, init_scale: float = 0.02):
        super().__init__()
        self.n_q = n_q
        self.embeddings = nn.ModuleList([
            nn.Embedding(vocab_size, hidden_dim) for _ in range(n_q)
        ])
        for emb in self.embeddings:
            nn.init.normal_(emb.weight, mean=0.0, std=init_scale)

    def forward(self, codes: torch.Tensor) -> torch.Tensor:
        # codes: [B, n_q, T]; output: [B, T, hidden_dim]
        assert codes.shape[1] == self.n_q
        per_q = [self.embeddings[q](codes[:, q, :]) for q in range(self.n_q)]
        return torch.stack(per_q, dim=0).sum(dim=0)
```

**Step 4 — Implement `spike/src/spike/llm_on_tokens.py`** (~100–140 lines):

CLI command `evaluate`:

```python
# Pseudocode shape:
@app.command()
def evaluate(utterances: Path, out: Path, runtime: str = "rocm",
             max_new_tokens: int = 64, seed: int = 42):
    config = load_config(...)
    mimi, fe = load_mimi(...)
    adapter = MimiToQwenAdapter(...).to(device).eval()
    qwen = AutoModelForCausalLM.from_pretrained("Qwen/Qwen2.5-0.5B", revision=...)
    tokenizer = AutoTokenizer.from_pretrained("Qwen/Qwen2.5-0.5B", revision=...)
    qwen.to(device).eval()

    rows = [json.loads(l) for l in open(utterances)]
    results = []
    for row in rows:
        audio = load_wav(row["audio_path"], target_sr=24000)
        with torch.inference_mode():
            codes = encode(mimi, fe, audio, sr=24000)         # [1, 8, T]
            audio_embs = adapter(codes)                        # [1, T, 896]
            # Optional textual prefix: "User said:" decoded as embeddings via qwen.get_input_embeddings()
            prefix_ids = tokenizer("User said: ", return_tensors="pt").input_ids.to(device)
            prefix_embs = qwen.get_input_embeddings()(prefix_ids)   # [1, K, 896]
            inputs_embeds = torch.cat([prefix_embs, audio_embs], dim=1)
            out_ids = qwen.generate(inputs_embeds=inputs_embeds,
                                    max_new_tokens=max_new_tokens,
                                    do_sample=False)
            text = tokenizer.decode(out_ids[0], skip_special_tokens=True)
        results.append({
            "id": row["id"],
            "intent": row["intent"],
            "topic": row["topic"],
            "transcript_reference": row["transcript_reference"],
            "llm_output": text,
            "n_input_audio_frames": int(audio_embs.shape[1]),
            "manual_classification": None,    # filled by operator post-run
            "operator_note": None,
        })
    out.parent.mkdir(parents=True, exist_ok=True)
    out.write_text(json.dumps({
        "experiment": "llm-on-tokens-stretch",
        "n_utterances": len(results),
        "model_revisions": {...},
        "image_digest": ...,
        "seed": seed,
        "verdict": None,           # filled after operator classification (Step 6)
        "results": results,
    }, indent=2))
```

  - Errors during forward pass are caught per-utterance and recorded as `"manual_classification": "error"` with the exception message in `operator_note`.
